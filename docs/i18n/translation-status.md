# Translation Status

English is the **source of truth** for all documentation. Each translated page below records the
commit of its English source at which it was last synchronised. `tools/consistency_lint.py` (the
`i18n-freshness` check) fails when the English source has commits after that recorded commit —
flagging the translation as stale. To refresh a translation, update it and bump the recorded
`Source commit` in the same PR.
