# 2026-07-01 — Milestone 7: caching & optimization

## Done

- Application abstraction `ICacheService` (`GetOrCreateAsync<T>` with TTL + `RemoveAsync` invalidation).
- Infrastructure `CacheService : ICacheService` — a two-level read-through cache: L1 `IMemoryCache` in
  front of L2 `IDistributedCache`. L2 presence is decided from the stored bytes (so a cached `default(T)`
  is not a miss); an L2 hit is promoted into L1; a miss writes L2 then L1 with `AbsoluteExpirationRelativeToNow`;
  a `null` factory result is returned but not cached. Abstractions-only dependency
  (`Microsoft.Extensions.Caching.Abstractions`). Proxy pattern (ADR-0009).
- Infrastructure `DistributedCacheExtensions` — typed `GetAsync<T>`/`SetAsync<T>` over `IDistributedCache`
  in compact UTF-8 `System.Text.Json`; an internal `CacheSerializer` shares the options with `CacheService`
  so entries are interchangeable.
- 109 tests (24 new): fast two-level + serialization unit tests over `MemoryCache`/`MemoryDistributedCache`
  (value-type/default handling, promotion, write-through, invalidation, null-not-cached, guards) plus a
  Testcontainers Redis integration suite (`[SkippableFact]`) — the round-trip and two-level read-through
  against real Redis. build `-warnaserror`, `dotnet format`, and `dotnet restore --locked-mode` all green.

## Testcontainers / Docker

- `Build()` contacts Docker eagerly (Testcontainers 4.x), so container `Build()` + `StartAsync()` are guarded
  in `InitializeAsync`; the Redis tests **skip** (not fail) when Docker is absent — the macOS/Windows CI cells
  and dev boxes without Docker — while the Linux CI cell runs them for real. Verified locally: the 2 Redis tests
  skip; the other 107 pass.
