# 2026-07-01 — Documentation i18n (Chinese + Japanese)

Post-1.0 documentation work (Milestone 9): translate the README into Simplified Chinese and Japanese,
turning on the previously-dormant i18n scaffolding. English stays the source of truth (ADR-0011).

## Done

- Enabled `i18n_enabled` in `tools/consistency_lint.py` (activates the `i18n-freshness` check).
- Added `docs/i18n/` with an index (`README.md`) and the freshness manifest (`translation-status.md`),
  which pins each translation to the English source's commit (`bd4c408`).
- Translated the README into **Simplified Chinese** (`README.zh-CN.md`) and **Japanese** (`README.ja.md`),
  placed at the repo root beside `README.md` so their relative links resolve verbatim; each carries a
  language-switcher line. Produced and adversarially fidelity-verified via a translate→verify workflow.
- ADR-0011 records the policy and qualifies AGENTS.md §2 (added the exception clause).

## Design note

- **`README.md` is deliberately not modified** (no language switcher added to it). Touching the tracked
  source would, through the squash-merge, make the manifest's recorded commit trail HEAD and fail the
  `i18n-freshness` check. Discovery is via the switcher on the translated pages and the `docs/i18n/` index.
- Milestone 9 is tracked in ROADMAP but not the README milestone table (same reason).
