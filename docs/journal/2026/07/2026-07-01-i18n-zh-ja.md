# 2026-07-01 — Documentation i18n (Chinese + Japanese)

Post-1.0 documentation work (Milestone 9): translate the README into Simplified Chinese and Japanese,
turning on the previously-dormant i18n scaffolding. English stays the source of truth (ADR-0011).

## Done

- Enabled `i18n_enabled` in `tools/consistency_lint.py` (activates the `i18n-freshness` check).
- Added `docs/i18n/` with an index (`README.md`) and the freshness manifest (`translation-status.md`),
  which pins each translation to a **SHA-256 content digest** of the English source.
- Translated the README into **Simplified Chinese** (`docs/i18n/zh/README.md`) and **Japanese**
  (`docs/i18n/jp/README.md`) — one folder per language under `docs/i18n/` — with repo-relative links
  rewritten with a `../../../` prefix; each carries a language-switcher line. Produced and adversarially
  fidelity-verified via a translate→verify workflow.
- ADR-0011 records the policy and qualifies AGENTS.md §2 (added the exception clause).

## Design note

- The `i18n-freshness` check is **content-digest based** (SHA-256 of the English source), not
  commit-based — so it survives the repository's squash-merge and lets `README.md` be edited freely:
  change the source, re-sync the translations, and record the new digest, all in one PR. (A commit-SHA
  anchor could not reference the not-yet-created squash commit and would leave `main` red.)
- With that in place, `README.md` now carries the badge row, quick-start, and a language switcher; the
  translated pages mirror it. `ROADMAP.md` and the translations moved under `docs/`.
- Milestone 9 (docs-infra) is tracked in `docs/ROADMAP.md`, not the README milestone table (which tracks
  the product milestones 1–8).
