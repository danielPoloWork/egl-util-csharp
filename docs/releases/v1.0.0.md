# egl-util-csharp v1.0.0

The first stable release — strongly-typed **DDD, Clean Architecture, CQRS, and functional-Result**
building blocks for **.NET 8 / C# 12**, shipped as the single `It.D4np.Util` NuGet package. The
public surface is frozen under Semantic Versioning (ADR-0010).

## Highlights

- **Domain** — `Entity<TId>`, `ValueObject`, `AggregateRoot<TId>`, `IDomainEvent`, and the functional
  `Result` / `Result<TValue>` / `Error` model. Zero third-party dependencies.
- **Application** — `IRepository<TEntity, TId>`, `ISpecification<TEntity>` (+ `Specification<TEntity>`),
  `IUnitOfWork`, `IEventBroker` / `IEventHandler<TEvent>`, `IPasswordHasher`, `ICacheService`,
  `IDateTimeProvider`, `ValidationPipelineBehavior<TRequest, TResponse>`, `DomainEventNotification<TEvent>`,
  and `PaginatedList<T>`.
- **Infrastructure** — `SpecificationEvaluator` (EF Core), `EventBroker` (Channels), `PasswordHasher`
  (PBKDF2-HMAC-SHA256, ≥ 600k iterations, constant-time verify), `CacheService` (two-level cache) +
  `DistributedCacheExtensions`, `DateTimeProvider`, `DbContextExtensions`, and
  `ServiceCollectionExtensions.AddD4npUtil(...)` for one-call DI registration.

## Install

```bash
dotnet add package It.D4np.Util
```

Requires .NET 8. Targets `net8.0`; built and tested green on Linux, Windows, and macOS.

## Quality

- Full CI matrix (Linux / Windows / macOS) green; nullable + Roslyn analyzers as errors; `dotnet format`
  clean; the Redis layer integration-tested against real Redis via Testcontainers.
- Line coverage 96.5% (≥ 80% bar, ADR-0010).
