# egl-util-csharp v2.0.0

The second major release — **DDD, Clean Architecture, CQRS, and functional-Result** building blocks for
**.NET 8 / C# 12**. 2.0 rolls up the breaking changes held back for a major cut, plus a large body of
additive building blocks and hardening accrued since 1.0.0. The 2.x public surface is protected under
Semantic Versioning.

The full detail (every entry, with issue/ADR links) is in the [changelog](../changelog/v2/v2.0.0.md); this
page is the curated summary and migration guide.

## ⚠️ Breaking changes (migration)

- **MediatR/FluentValidation are now an opt-in package (ADR-0037).** `DomainEventNotification<TEvent>` and
  `ValidationPipelineBehavior<TRequest, TResponse>` moved out of the core into the new **`It.D4np.Util.MediatR`**
  package, so `It.D4np.Util` no longer pulls MediatR or FluentValidation. **Migrate:** if you use those types,
  `dotnet add package It.D4np.Util.MediatR`; change the usings to `It.D4np.Util.MediatR` /
  `It.D4np.Util.MediatR.FluentValidation`; and call `AddD4npUtilMediatRValidation(...)` (or the umbrella
  `AddD4npUtilMediatR(...)`) after `AddD4npUtil(...)` — otherwise your FluentValidation validators silently
  stop running in the MediatR pipeline.
- **Canonical-type entity equality (ADR-0028).** `Entity<TId>` / `AggregateRoot<TId>` are now self-referencing
  generics — `Entity<TId, TEntity>` / `AggregateRoot<TId, TAggregate>`. **Migrate:** close the generic over the
  type itself — `class Order : AggregateRoot<Guid, Order>`, `class Customer : Entity<Guid, Customer>`;
  `IRepository<TEntity, TId>`'s constraint is now `AggregateRoot<TId, TEntity>`. There is no longer a common
  non-generic `Entity<TId>` base. Fixes EF-proxy equality (#26) and transient-identity collisions (#25).
- **The implicit `Error` → `Result<TValue>` conversion is removed (ADR-0020).** It collided with the `TValue`
  → `Result<TValue>` conversion. **Migrate:** create failures with `Result.Failure<TValue>(error)`
  (`return someError;` → `return Result.Failure<TValue>(error);`).
- **Variance-aware event dispatch (ADR-0027).** `EventBroker` now delivers an event to handlers registered
  for its base types and implemented interfaces (honoring `IEventHandler<in TEvent>`), not just its exact
  runtime type. Base-typed/interface handlers that silently never fired now fire — review such registrations.
- **`LibraryVersion.Version` is a runtime-resolved property, not a `public const` (ADR-0030).** A consumer
  compiled against the 1.x `const` must be recompiled to pick up the property, and `Version` can no longer be
  used in a `const` context.

Also behavior-tightening (surfaces latent misuse; each detailed in the changelog): the cache fails fast on a
non-round-trippable `T` (#33), `SpecificationEvaluator` rejects a both-orderings spec (#88), `AddD4npUtil` no
longer auto-registers `ISpecification<>` (#67), and `Result.Failure` rejects `Error.None` / `null` (#29, #53).

## Added & improved (highlights)

- **Functional `Result` combinators** — `Match`/`Map`/`Bind` and non-throwing `GetValueOrDefault`/`TryGetValue`
  (ADR-0034); **Specification predicate composition** — `And`/`Or`/`Not` + `IsSatisfiedBy` and `ThenBy`
  secondary ordering (ADR-0033, ADR-0025); **reachable pagination** — `SpecificationEvaluator.ToPaginatedListAsync`
  (ADR-0035).
- **`TimeProvider` interop** — `AddD4npUtil` registers `TimeProvider.System` and `DateTimeProvider` bridges to
  it (ADR-0036); **opt-in cache-stampede coalescing** — `CacheService(..., coalesceConcurrentMisses: true)`
  (ADR-0039); a **`DomainEventNotification` factory** for runtime-typed events (ADR-0026); **`IPasswordHasher`**
  rehash detection + span overloads (ADR-0029).
- **Resilience/observability** — `EventBroker` failures are observable via an `EventSource` even without a
  logger (#43), handler **construction** failures are isolated (ADR-0038), overriding `IEventBroker` fully
  replaces the default (#92), and the per-event dispatch cache is per-broker (#44). Plus many correctness
  fixes across the cache, broker, and Result model — see the changelog.
- **Supply chain & CI** — CodeQL, dependency review, and a per-package CycloneDX SBOM (ADR-0031); a real
  analyzer gate (ADR-0032); locked-mode restore + lockfile-presence (ADR-0014/0015); SourceLink + debuggable
  symbols for all layers (#36, #66); package validation enabled (#64).

## Install

```bash
dotnet add package It.D4np.Util
```

Opt into the MediatR/FluentValidation integration only if you need it:

```bash
dotnet add package It.D4np.Util.MediatR
```

Requires .NET 8. Targets `net8.0`; built and tested green on Linux, Windows, and macOS.

## Quality

- Full CI matrix (Linux / Windows / macOS); nullable + Roslyn analyzers as errors; `dotnet format` clean; the
  Redis layer integration-tested against real Redis via Testcontainers; ≥ 80% line coverage (ADR-0010/0016).
