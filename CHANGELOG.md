# Changelog

All notable changes to `egl-util-csharp` are documented here, following
[Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/) and
[Semantic Versioning 2.0.0](https://semver.org/).

Every PR that introduces a user-visible change adds a line to `[Unreleased]` in the same
PR. A release PR moves the `[Unreleased]` entries into a new per-version file under
`docs/changelog/v<MAJOR>/v<X.Y.Z>.md` and adds an index row below.

## [Unreleased]

### Added

- Project bootstrap: enterprise scaffolding generated by EADOS (agent contract, docs system,
  CI gate, consistency lint).
- DDD core building blocks (Milestone 2): `Entity<TId>`, `ValueObject`, `AggregateRoot<TId>`,
  `IDomainEvent`, and `DomainEventNotification<TEvent>` — split into the dependency-free
  `It.D4np.Util.Domain` assembly and the `It.D4np.Util.Application` assembly (MediatR).
- Functional Result error model (Milestone 3): `Result`, `Result<TValue>`, the immutable `Error`
  record (with `Error.None`), and `Result.Combine` — in the dependency-free `It.D4np.Util.Domain`
  assembly.
- Persistence patterns (Milestone 4): `IRepository<TEntity, TId>`, `ISpecification<TEntity>` with a
  `Specification<TEntity>` base, and `IUnitOfWork` in `It.D4np.Util.Application`; plus a new
  `It.D4np.Util.Infrastructure` assembly (EF Core) providing `SpecificationEvaluator` and
  `DbContextExtensions` (at-least-once domain-event dispatch).
- In-memory eventing (Milestone 5): `IEventBroker` (async publish) and `IEventHandler<TEvent>` in
  `It.D4np.Util.Application`; `EventBroker` — a `System.Threading.Channels` background consumer with
  back-pressure, per-handler failure isolation, and a graceful drain — in `It.D4np.Util.Infrastructure`.
- Security & validation (Milestone 6): `IPasswordHasher` (Application) and `ValidationPipelineBehavior<TRequest, TResponse>`
  — a MediatR pipeline behavior running FluentValidation validators — (Application); plus `PasswordHasher`
  (PBKDF2-HMAC-SHA256, 128-bit salt, ≥ 600,000 iterations, constant-time verify, self-describing versioned
  hash) in `It.D4np.Util.Infrastructure`.
- Caching & optimization (Milestone 7): `ICacheService` (Application); `CacheService` — a two-level
  (`IMemoryCache` L1 + `IDistributedCache` L2) read-through cache — and `DistributedCacheExtensions`
  (typed get/set over `IDistributedCache` using compact `System.Text.Json`) in `It.D4np.Util.Infrastructure`.
  The Redis layer is integration-tested via Testcontainers (skipped when Docker is unavailable).
- Utilities & DI (Milestone 8): `IDateTimeProvider` and `PaginatedList<T>` (Application); `DateTimeProvider`
  and `ServiceCollectionExtensions.AddD4npUtil(...)` — one-call registration plus assembly-scanning
  auto-registration of event handlers, validators, and specifications — (Infrastructure).

### Changed

- `It.D4np.Util.Application` now references the full `MediatR` package (12.5.0, for `IPipelineBehavior`)
  and `FluentValidation` (11.11.0), superseding its prior `MediatR.Contracts`-only reference.
- `It.D4np.Util.Infrastructure` now references `Microsoft.Extensions.Caching.Abstractions` (8.0.0) for the
  two-level cache.
- `It.D4np.Util.Infrastructure` also references `MediatR` (12.5.0) and `FluentValidation` (11.11.0) for
  DI wiring, and is now the single packable project: the `It.D4np.Util` NuGet package bundles the Domain,
  Application, and Infrastructure assemblies (with XML docs and README).
